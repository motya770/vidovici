# Vidovici

A dating app where personality comes first. Instead of photos, Vidovici generates personalized ChatGPT prompts that help you discover potential matches through their interests, values, hobbies, and what makes them unique.

## How it works

1. **Create your profile** — Share your hobbies, favorite books, education, values, and describe yourself in your own words
2. **Discover people** — Swipe through profiles that highlight personality traits, interests, and compatibility
3. **Get your prompt** — Tap "Get Prompt" to receive a ready-to-use ChatGPT prompt that describes your match positively and explores your compatibility
4. **Paste into ChatGPT** — Copy the prompt, paste it into ChatGPT, and get a thoughtful, warm description of the person and why you might connect

## Tech stack

- React Native + Expo
- TypeScript
- React Navigation
- AsyncStorage for local profile persistence

## Getting started

```bash
npm install
npx expo start
```
